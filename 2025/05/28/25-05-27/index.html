流水账

昨天竟然五点就睡着了，中午十二点醒了（好像跟我之前1点睡，起床时间差不多啊）。

起床后洗了个衣服，点个外卖，把跨专ppt的图片又补充了一点，然后速成了一波java语法，让gpt给我生成了一个十天速成计划哈哈哈哈，看看能干到什么程度吧，毕竟还要准备期末考试/(ㄒoㄒ)/~~ ，看看能不能报一个OSPP的项目，感觉自己的技术栈约等于0，速速学一波

然后去旁听了一个学长学姐的求职分享，但是感觉好像参考价值不高，一个是游戏策划，不是纯粹的研发岗，一个是华为光产品线，虽然都是大厂，但是感觉这俩岗位都不太感兴趣啊。但是还是挺给人信心的，两个学长学姐在实习转正之前都没有过实习经历（但是他们是计卓的，而且绩点都很高啊。。。。）

在听分享期间把Ubuntu vscode的java环境给配置了一下，再用git，也可以实现协作开发了。
然后终于是把最优化方法的第一章给学完了，感觉真的是抽象的不行啊

从青楼回来换了身衣服，然后去桂操跑步了，跑了大概两公里，感觉比昨天要轻松一些，然后跳绳任务也是完美完成了，但是快自律完的时候下雨了，狼狈找车终于是回到宿舍了。

回到宿舍竟然外卖一个小时了还没到，打个电话催了一波，去门口便利店买了两桶泡面回来美美拿着外卖回宿舍。

吃完炸鸡外卖，干了两三个小时，终于是把数据结构的树给干完了，线索二叉树是真的抽象，看代码理解了半天，澡都没洗，干到现在，终于一天是结束了。

感觉拖着累累的身体强撑着干完计划还是效率太低了，以后要及时调整了啊，争取效率最大化！

最近的话感觉还是 java + 最优化方法 + 操作系统 三线并行吧，数据结构的话顺便学一学。

求职分享会

虽然感觉实际听这个分享会学到的东西不多，但是至少也是开阔了一点点眼界，也增长了一点信心（比如小学期的项目也能写到简历里），然后就是内推真的很有用，也不要担心自己太菜了，发现学长学姐的履历好像也没有比我强很多啊哈哈哈哈哈。
